# 🎓 Placement Portal

> A full-stack web application that helps colleges manage the complete placement process — from student registration and job applications to eligibility checking, skill-gap analysis, and placement analytics.

## 💡 What Does This Project Do?

Placement Portal connects **students** and **placement officers** in one platform.

### 👨‍🎓 Students can:

- Create and manage their placement profile
- Upload their resume
- Browse available jobs
- Check whether they are eligible for a job
- Apply for jobs
- Track application status
- Get job recommendations
- Find missing skills required for jobs

### 👨‍💼 Placement Officers can:

- Manage students
- Manage companies
- Create and manage job openings
- Review student applications
- Shortlist or reject candidates
- Track placement statistics
- View placement analytics

### 🧠 Smart Features

The system automatically compares a student's profile with job requirements such as:

**CGPA + Branch + Backlogs + Skills**

and determines eligibility.

It also identifies **missing skills** and provides relevant job recommendations.
